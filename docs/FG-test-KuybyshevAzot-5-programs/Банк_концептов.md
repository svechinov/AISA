## Общие решения по всем пяти программам

- **Формы работы 20/60/20** — устойчивая формула FG, сохранена; внутрь вписаны конкретные механики из архива: «скрытая роль», «Вертикаль», «карточка закупщика», кейс-вселенная, симуляция МЕРИДИАН.
- **Follow-up** в строке «Продолжительность» (онлайн-разбор через 3–4 недели, у команды — диагностика до и поддерживающая сессия после) — из методической рамки FG (`5 программ к тендеру\реф-методика.md`: follow-up через 1–2 недели с артефактом и peer check-in).
- **Дозировка ИИ** по правилу из письма: по одному пункту в программах 1, 4 и 5; в программах для мастеров и команды ИИ не упоминается.
- **Язык результатов** — «смогут… / инфинитивы», как в образце Treolan; в пунктах модулей — конкретные названия моделей и алгоритмов вместо общих слов.

- **S.H.I.V.A.-мир** (5 архетипов кризиса) и **полная модель вертикального лидерства** (5 персонажей) из Триатлона — сильные, но требуют своей программы; в двухстраничном описании превратятся в набор непонятных слов.
- **Когнитивный лифт / протокол У.Д.А.Р. / ап-фрейминг** (ВТБ) — заточены под сервисные и холодные продажи банка; для промышленного B2B в переговорах с закупщиком уместнее книга «Теория пяти программ». При желании ап-фрейминг (перевод возражения на уровень выше) можно добавить в модуль 4 переговоров.
- **Polarity Management, ERG, Hay Group** — встречаются в архиве по разу, в описании программы веса не добавят.
- Формулировки из NotebookLM-колод, которые не подтверждены исходниками (порядок шагов PSF, перепутанные типы сотрудников).

## Что строим

Три движковые доработки в основной ветке `fork-base` (все — паттерном «данные + фоллбэк»,
кандидаты на возврат партнёру): настраиваемый лимит объёма письма, скоуп каталога программ по
персоне, XLSX-экспорт черновиков рана. Поверх — `seed_fg_preset.py`: персона FG и матрица
профилей «5 отраслей × 2 рамки письма» с контент-плейсхолдерами (реальные тексты FG ещё
в проработке). Плюс упразднение ветки `track/fg`. Итог фазы: сквозной смок обеих рамок на
`fresh_db` проходит, экспорт отдаёт валидный XLSX, письма AlexStaff-персон не изменились ни на байт.

## Ключевые решения (не переоткрывать; все — владелец, 02.09.2026)

- **A. Один инстанс движка, две кампании** (NODA12 + FG). Оператор ближайшие 1–2 мес — Алексей,
  один интерфейс. Отсюда: скоуп каталога обязателен, `track/fg` упраздняется, `seed_fg_preset.py`
  живёт в основной ветке. «Двух форков» кода нет — код один.
- **B. Экспортный канал по существующей базе FG:** движок генерирует, менеджеры FG отправляют
  вручную со своих ящиков. Транспорт этому каналу не нужен; черновики НЕ аппрувить
  (approve = автопостановка в очередь) — цикл «ревью → экспорт».
- **C. Две рамки письма (A/B):** Рамка‑1 точная (одно решение, матчер), Рамка‑2 широкая (веер
  «название + предложение»). Сплит выборки отрасли между двумя ранами; сверка эффективности —
  фидбек менеджеров (Tracking ответов по экспортному каналу не видит).
- **D. Лимит объёма — настраиваемый,** фоллбэк на текущие 120–140/180 байт-в-байт.
- **E. Минихук — только при крутом OSINT-поводе,** через draft_prompt пресета, не через код.
- **F. Свежесть отраслевых ревю — горизонт ~полгода;** процесс актуализации — операционка,
  не код этой фазы.
- **G. Письма персон AlexStaff не меняются ни на байт.** Регресс-доказательство:
  `test_persona_finale_regression.py`, `test_hard_rules_gate_b273.py`,
  `test_email_validation_b063.py`, `test_email_validation_b077.py` — зелёные без правок.
  Все правки — «данные + фоллбэк», возвращаемые партнёру.
- **H. Task 10 — вне фазы** (владелец, 02.09); Task 9 ждёт сервера (перенос NODA12-продукта —
  отдельная сессия, он сейчас развёрнут локально).
